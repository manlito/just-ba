Incremental reconstruction in your browser

A small structure-from-motion run on a generated capture: every pair's matches are verified by relative pose in RANSAC, the first pair gives the first points, and each further image is registered by PnP, triangulated and bundle-adjusted. Both the pose estimation and the bundle adjustment run in WebAssembly, on WebGPU or the CPU. The scene has a known ground truth, so the result is checked against it.
